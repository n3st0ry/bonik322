# NYTHRAVEL 4.0

[Скачать NYTHRAVEL.zip](https://github.com/n3st0ry/bonik322/raw/refs/heads/download/nythravel/NYTHRAVEL.zip)

Кооперативная 2D RPG для 1–3 игроков. Новый кристальный логотип, favicon, тёмный фэнтезийный фон и единый интерфейс. Сохранены классы, боевые механики, навыки, противники, боссы, этапы и подключение по IP/коду.

Добавлены:

- Быстрая/массовая продажа с фильтрами, избранным и подтверждением.
- Серверная экономика и атомарный обмен предметами/золотом с двумя подтверждениями.
- Физическая лавка с NPC, E, безопасным прилавком и отметкой на карте.
- 39 новых предметов, расходники, требования, перчатки/талисманы и предметное оружие.
- Пауза, настройки звуков интерфейса, защита перезапуска от старых пакетов.

Характеристики противников и вероятности выпадения не изменены. Совместимые технические ключи сохранены.

## Запуск

Node.js 20+. Распакуйте ZIP и откройте терминал в папке NYTHRAVEL:

```sh
npm install
npm start
```

Откройте http://localhost:3000. Для друзей: Мультиплеер → «Создать игру по IP» / «Подключиться по IP», затем хозяин нажимает «Начать игру».

Внутри архива: полный исходный проект, все локальные графические ресурсы, README.md для Windows, ITEMS.md, COMPATIBILITY.md, ARTWORK.md и TEST_REPORT.md.

Проверено из распакованного ZIP: чистая установка, синтаксис, 19 тестов Node.js и три браузерных сценария с 1/2/3 игроками. Реальные устройства/Windows и длительное прохождение требуют ручной проверки.
