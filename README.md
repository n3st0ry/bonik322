Обновление существующей игры: тактические враги с предупреждениями атак и обходом препятствий; пять редкостей с отдельным шансом предмета; 22 навыка в четырёх ветках с растущей ценой и выносливостью; новое главное меню, лобби, инвентарь и HUD. Классы, боссы, этапы и кооператив сохранены.

## Запуск

Node.js 20+. Распакуйте ZIP, откройте терминал в папке Realm_of_Shards:

```sh
npm install
npm start
```

Хозяин: Мультиплеер → **Создать игру по IP**. Гости открывают `http://IP-ХОЗЯИНА:3000` → Мультиплеер → **Подключиться по IP**. Код не нужен. Затем хозяин нажимает «Начать игру». Обычные комнаты с кодами тоже сохранены.

Внутри: README.md с инструкцией Windows и таблицами баланса; TEST_REPORT.md с результатами и ограничениями. Параметры меняются в balance-config.js.

Проверки: 9 Node.js-тестов, два браузерных сценария с 1/2/3 игроками, 2 млн бросков редкости и 1 млн проверок шанса предмета. Установка и тесты повторены из распакованного ZIP. Реальные устройства, Windows и длительный баланс требуют ручной проверки.
