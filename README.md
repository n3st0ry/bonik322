Пассивное лечение и похищение жизни ограничены. При добавлении новых систем шансы сундуков и веса редкости сохранены.

## Запуск

Node.js LTS 20+. Распакуйте ZIP, откройте терминал в папке NYTHRAVEL:

```sh
npm install
npm start
```

Откройте http://localhost:3000. Для друзей: Мультиплеер → Создать игру по IP / Подключиться по IP; хозяин явно начинает партию. Для игры через интернет сервер должен быть доступен извне.

Проверены чистая установка по lockfile, синтаксис 15 модулей, 30 тестов Node.js и пять браузерных сценариев, в том числе 2/3 сетевых клиента. Все исходники, изображения и звуки включены в ZIP и папку NYTHRAVEL. Windows, реальные устройства/интернет и длительные сессии требуют ручной проверки. Озвучка торговца синтезированная английская с русским текстом. Полного серверного античита и постоянных сохранений нет; подробности в отчёте.
