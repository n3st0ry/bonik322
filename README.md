## Запуск на Windows

Установите **Node.js LTS 20+**, распакуйте архив целиком и дважды нажмите **START_NYTHRAVEL.bat** в папке NYTHRAVEL. Он установит зависимость, запустит сервер и откроет игру по HTTP. Оставьте окно сервера открытым.

Через терминал: `npm install`, затем `npm start`; откройте http://localhost:3000.

Открытие rpg.html как file:///… вызывает блокировку fetch/CORS с origin null. Исправленная сборка выявляет это до запуска игровых модулей и показывает инструкцию. CORS и защита браузера не отключаются.

Загрузчик проверяет порядок модулей, версию, HTTP/MIME и обязательные изображения, показывает этап/имя ошибки, ограничивает ожидание и позволяет повторить загрузку. Необязательный логотип/фон не блокируют игру. Все механики версии 6 и баланс сохранены.
