NYTHRAVEL 6.0.1 — исправление запуска

WINDOWS: установите Node.js LTS 20+, распакуйте архив целиком,
затем дважды нажмите START_NYTHRAVEL.bat.
Он установит зависимость, запустит сервер и откроет игру по HTTP.
Не закрывайте окно сервера во время игры. Остановка — Ctrl+C.

Через терминал в папке с package.json:
  npm install
  npm start
Откройте http://localhost:3000

Открытие rpg.html как file:///… блокируется браузером (CORS/origin null).
Вместо повторного открытия HTML используйте START_NYTHRAVEL.bat.
Не требуется отключать CORS или защиту браузера.
