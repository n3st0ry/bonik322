NYTHRAVEL 6.0

Установите Node.js LTS 20+. В терминале папки с package.json:
  npm install
  npm start
Откройте http://localhost:3000. Остановка — Ctrl+C.
Не запускайте server.js через Windows Script Host.

Кооператив без кода: хозяин — «Создать игру по IP»;
гости открывают адрес сервера и выбирают «Подключиться по IP».
Затем хозяин нажимает «Начать игру». Максимум три игрока.

Большой мир, новые спрайты/анимации, прицел мышью, локальные звуки,
лавка по референсу, инструменты/серверная добыча, покупки за материалы,
кузница до +5 (+10%), новый HUD, круглая мини-карта, задания (J),
души, магазин душ и навык «Похищение жизни». Продажа и обмен сохранены.
