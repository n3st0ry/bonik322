# NYTHRAVEL 6.0

Кооперативная 2D RPG для 1–3 игроков на JavaScript/Canvas, Node.js и WebSocket. Обновлена существующая игра: сохранены пять классов, навыки, инвентарь, экипировка, продажа, обмен, биомы, противники, боссы и этапы.

## Запуск

Установите Node.js LTS 20+. Распакуйте архив целиком, откройте терминал в папке **NYTHRAVEL**, где находится package.json:

```powershell
npm install
npm start
```

Откройте **http://localhost:3000**. Остановка сервера — Ctrl+C. Не запускайте server.js двойным щелчком через Windows Script Host. Для воспроизводимой установки вместо npm install используйте npm ci. Если порт занят: в PowerShell выполните `$env:PORT=3001`, затем npm start.

## Подключение друзей по IP

Хозяин запускает сервер → **Мультиплеер → Создать игру по IP**. Терминал выводит адрес, например `192.168.1.100:3000`. Друзья открывают `http://192.168.1.100:3000`, выбирают имя и класс → **Подключиться по IP**. Код не нужен; хозяин нажимает **Начать игру**, когда все готовы. Максимум — три игрока. Сохранены и отдельные комнаты с шестизначным кодом.

Для устройств одной сети разрешите Node.js в брандмауэре. Для игры через интернет сервер должен быть доступен извне: локальный IP сам по себе этого не обеспечивает. HTTPS использует WSS. После начала подключиться нельзя. Выход хозяина закрывает партию. Положение игроков по-прежнему ограничено общей игровой камерой.

## Мир, графика и боевые механики

- **Мир 7200×4800**: вчетверо больше прежней площади. Два лесных массива, семь именованных точек, лагеря, руины, кристальный карьер, дороги, вода и проходимый мост. 480 ресурсов, безопасное начало, коллизии, мини-карта. Генерация одинакова для участников комнаты; новая партия получает новый seed. Дальние ресурсы/враги не рисуются, фон хранится в ограниченном кэше чанков.
- **Новые персонажи**: пять разных силуэтов, по восемь кадров для ожидания, ходьбы, атаки, ранения и смерти. Скорость шага зависит от движения. Оружие вращается в сторону мыши; можно идти вправо и атаковать влево. Ближний бой проверяет сектор и дальность, стрелы/магия появляются у руки. Направления и состояния передаются другим игрокам.
- **Новые противники**: 19 обычных архетипов и девять обликов боссов/мини-боссов/разломов. Движение конечностей, замахи, вспышки ранения, падение и исчезновение тел; метки элитных врагов и предупреждения атак сохранены. Охрана точек интереса появляется при приближении группы.
- **Лавка по вашему референсу**: пожилой торговец за деревянным прилавком, фиолетовая ткань, фонари, кристаллы, зелья, сундук и оружие. Три варианта ожидания и жест приветствия. Три короткие озвученные реплики с русским текстом и паузой не менее 25 игровых секунд. Озвучка синтезированная, на английском.
- **Локальные звуки**: меч, топор, кинжал, лук, стрела, магия, попадание, броня, крит, добыча и семейства врагов. Варианты и небольшой разброс тона, затухание по расстоянию и стереопанорама. Максимум 18 эффектов, пять боевых голосов и три фоновых; фон отдельного врага проверяется раз в 20–40 секунд с 70% пропусков. Громкость эффектов настраивается отдельно. Музыкальная дорожка не добавлена.
- **Добыча**: дерево требует принадлежащего игроку топора, камень — кирки. Выберите инструмент клавишей C, наведите курсор и атакуйте. Обычный топор добывает дерево за четыре удара, кирка камень за пять; улучшенный инструмент наносит два пункта прочности. Дерево даёт четыре древесины, камень — три камня. Восстановление через 60 игровых секунд в одиночной игре; в сети — через 60 секунд серверного времени. Сервер проверяет владельца, расстояние, направление, инструмент, частоту, повтор и истощение объекта.
- **61 товар**: сохранены прежние предметы, добавлены инструменты, материалы, новое снаряжение, специальные предложения и шесть товаров за души. Некоторые покупки требуют золото и материалы. Все валюты списываются одновременно после проверки; нехватка материалов подсвечивается. Счётчики дерева/камня есть в HUD, инвентаре и лавке. Полный каталог — ITEMS.md.

### Сундуки и сложность

| Источник | Шанс сундука |
|---|---:|
| Обычный враг | 0,3% |
| Элитный | 2% |
| Мини-босс | 10% |
| Босс | 30% |

Веса редкости **внутри выпавшего сундука** сохранены. Сундуки за выполненное задание остаются отдельной гарантированной наградой. Повторное убийство/открытие не выдаёт награду снова. Конфигурация — balance-config.js.

Относительно версии 4: у обычных врагов +12% HP и +25% урона; элитный множитель урона увеличен на 20%; у боссов +12% HP и +18% урона. Это однократные изменения базовых параметров, без повторного умножения при запуске.

**Похищение жизни**: пять рангов по 0,5% фактического урона, максимум 2,5%; стоимость 2/3/4/5/6 очков, требуется второй ранг крита. Лечение ограничено 1,5% максимального HP за игровой секундный интервал. Избыточный урон по убитому врагу не учитывается; ресурсы не лечат. Без навыка лечение от нанесения урона отсутствует. Убраны лечебные выпадения за убийства, бесплатное межволновое лечение и восстановление HP при повышении уровня. Навык восстановления вне боя, лечение/зелья и кооперативное воскрешение сохранены. Прежний бонус предметов `vp` теперь восстанавливает выносливость, не давая бесплатного вампиризма.

## Кузница, задания и души

**Кузница:** пять рангов, суммарно +2 / +4 / +6 / +8 / +10% к базовой части урона, без сложения старых глобальных и оружейных уровней. Заточка хранится для боевого семейства и сохраняется при смене предмета. Навыки, класс, редкость и бонусы экипировки учитываются в показанных итоговых характеристиках. Старые уровни выше пятого безопасно ограничены в расчёте без удаления предметов.

| Новый ранг | Золото | Древесина | Камень | Кристальная пыль |
|---|---:|---:|---:|---:|
| +1 | 25 | 3 | 4 | 0 |
| +2 | 100 | 6 | 8 | 0 |
| +3 | 225 | 9 | 12 | 0 |
| +4 | 400 | 12 | 16 | 1 |
| +5 | 625 | 15 | 20 | 2 |

Окно «Кузница» показывает оружие, текущий/следующий урон, ранг и все материалы. Улучшение подтверждается кнопкой и проверяется сервером. Неудачная проверка ничего не списывает; разрушения оружия нет. Кузница также доступна по E у наковальни справа от лавки. Старые входы через навыки сохранены и используют те же формулы.

**Магазин:** оружие, броня, аксессуары, зелья, инструменты, материалы, особые товары, продажа и магазин душ. Есть сортировка, сравнение со снаряжением и обозначение недостающих материалов. Новые торговые этапы открываются на волнах 1/4/7/10/13 и сохраняются до конца партии. Базовые товары остаются; заблокированные карточки показывают нужный этап. Два специальных предложения имеют фиксированную скидку; бесконечной прибыли от перепродажи нет. Материалы поступают сразу в счётчики и не засчитываются как личная добыча.

**Журнал J:** десять доступных с начала партии заданий: охота, слизни, элиты, дерево, камень, руины, исследование, этап, босс и кузница. Добыча/исследование/кузница — личные. Боевые задания намеренно групповые и учитываются только рядом с группой (до 900 единиц мира). Каждый игрок отдельно получает награду один раз. Золото — 25–150 за задание; некоторые сложные дают 1–2 души. Награда требует нажатия в журнале, появляется отдельное уведомление. Задание можно закрепить в HUD. Задания не перезапускаются бесконечно и сохраняются между этапами текущей партии.

**Души** отделены от золота. Обычные враги дают 0, элитные — 1, мини-боссы — 3, боссы — 8 находящимся рядом участникам группы. Магазин душ продаёт кольца восстановления (14), стойкости (10), сосредоточения (12), амулет жизненной силы (14), талисман странника (10) и осколок восстановления (4). Кольцо даёт 0,2 HP/с, защита +2%, перезарядки −2%, HP +3%, скорость +2% соответственно. Осколок лечит 12% HP не чаще раза в 60 секунд. Покупки и использование проверяет сервер; души не обмениваются как золото и не заменяют золотые награды.

Один слот кольца, амулета и талисмана ограничивает сочетания. Пределы: регенерация от предметов 0,4 HP/с; все пассивные источники вместе, включая навык и ауру хиллера, максимум 1,2 HP за секундный интервал и только после четырёх секунд без урона. Предметные перезарядки ограничены 6%, процентный HP — 6%. Активное лечение и ограниченное похищение жизни остаются отдельными механиками.

**HUD:** справа сверху — собственный персонаж с крупной полосой HP, выносливостью, валютой и эффектами; союзники — компактными карточками. Слева сверху — круглый компас с направлением взгляда, ближайшими точками, союзниками, лавкой и кузницей. Снизу — рабочие кнопки способностей/расходников и полоса опыта. Компас сохраняет круглую форму и экранный размер при DPI/масштабировании.

## Продажа и обмен

Быстрая продажа доступна из инвентаря/магазина: фильтры редкости, индивидуальный выбор, избранное и подтверждение с точной суммой. Экипированные, избранные и выставленные в обмен вещи защищены. Обмен требует приглашения, принятия и двух подписей на одной версии предложения. Изменение вещей/золота сбрасывает подписи; перенос атомарный. Выход участника отменяет обмен. UID вещей сохраняются.

Торговля по E работает у прилавка; вне лавки E остаётся боевым навыком. Прилавок защищён от боя. B позволяет просматривать ассортимент, но сервер проверяет близость для покупки товаров NPC. Старые кузница/снаряжение/заточка сохранены.

## Управление

| Действие | Основной / сетевой игрок | Второй локальный |
|---|---|---|
| Движение | WASD | Стрелки |
| Прицеливание | Мышь | Направление движения |
| Атака / добыча | F или ЛКМ | Enter вне лавки |
| Рывок / нова / лечение | Q / E / R | I / O / P |
| Торговец | E рядом с NPC | Enter рядом с NPC |
| Оружие / инструмент | C | U |
| Навыки / магазин / инвентарь | T / B / V | Общие окна с выбором игрока |
| Журнал заданий | J | Общий журнал с выбором игрока |
| Пауза / закрытие окна | Escape | |
| Межволновой перерыв | N, в сети — хозяин | |
| Полный экран | Кнопка или F11 | |

Способности расходуют выносливость. Одиночная пауза останавливает игровое время. В сети окно паузы личное: группа продолжает игру, управление открывшего окно блокируется. Графика поддерживает низкое/высокое качество, DPI до 2× и уменьшение движений интерфейса. Игра рассчитана на клавиатуру/мышь.

## Архитектура и совместимость

Node.js хранит сетевые активы и ресурсные объекты, проверяет сделки и добычу. Одиночный режим использует ту же модель локально. Ресурсы передаются при старте и при изменениях; обычные снимки боя не содержат карту ресурсов. Хозяин остаётся доверенным источником боевой симуляции и наград: полной защиты от изменённого хозяина нет.

Постоянных сохранений и миграции хозяина не было и не добавлено. Партии живут в памяти процесса. Обновляйте сервер между партиями и страницы всех игроков вместе с ним. Сохранены `ros-quality`, `ROS_BALANCE`, внутренние типы сообщений и UID прежних предметов. Названия игровых сущностей не менялись, кроме запрошенного навыка. Подробности — COMPATIBILITY.md.

Основные новые файлы: progression-rules.js (кузница/задания/ограничения), progression-runtime.js (магазин/души/HUD/журнал), world-rules.js (генерация/добыча), world-runtime.js (мир/интеграция), audio.js (звук), visuals.js (спрайты/анимации). Все изображения и WAV находятся внутри assets, внешние ссылки для игры не нужны. Node-зависимость — ws; Playwright нужен только для проверок.

## Проверки

```powershell
npm run check
npm test
npx playwright install chromium
npm run test:browser
npm run test:tactical
npm run test:nythravel
npm run test:world
npm run test:progression
```

При наличии используется системный /usr/bin/chromium; другой путь задаётся CHROMIUM_PATH. Тесты запускают временные серверы, изолированные браузеры и проверяют одиночный, локальный и сетевой режимы. Скриншоты находятся в test-results и не включены в ZIP.

Фактические результаты и ограничения — **TEST_REPORT.md**; описание арта/звука — **ARTWORK.md**. Ручная проверка на реальных устройствах: подключить 1/2/3 игроков, пройти несколько биомов, купить инструменты, добыть оба ресурса, проверить покупки за материалы, обмен/продажу и паузу; проверить звук, F11 и длительную нагрузку. Windows, Wi-Fi/NAT, слабые GPU, Firefox/Safari не покрыты автоматикой Linux/Chromium.
