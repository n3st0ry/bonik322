# NYTHRAVEL 6.0.1 — исправление запуска

## Подтверждённая причина

В пользовательском журнале браузера указан запрос `file:///C:/.../NYTHRAVEL/assets/audio/boss-1.wav` с `origin null`, отклонённый политикой CORS. Игра открывалась напрямую как локальный HTML, а не через Node.js/HTTP. В `audio.js → initializeSounds()` относительный fetch разрешался в file://; браузер не разрешает такой запрос. Это не свидетельствует об отсутствии самого WAV-файла.

Предыдущий загрузчик в `visuals.js` объединял загрузку атласов, обновление портретов и запуск цикла в одном Promise.all/then/catch. Catch отбрасывал исходное исключение и показывал общий текст со скриншота. Кроме того, глобальный error-handler в rpg.html считал фатальным даже отказ декоративного логотипа. Воспроизведено в Chromium: отказ логотипа давал то же сообщение и останавливал запуск при исправных игровых модулях. Экспорт портрета из небезопасного Canvas также мог теряться за этим сообщением. Пользовательский журнал не позволяет восстановить самое первое исключение прежней попытки, но однозначно подтверждает неподдерживаемый file:// запуск и CORS аудио.

## Что исправлено

- **START_NYTHRAVEL.bat + launch.js:** запуск через Node.js с рабочей директорией самой игры, корректно заключёнными в кавычки путями и автоматическим открытием HTTP-адреса. Проверяется Node.js 20+, при необходимости устанавливается ws. Повторный запуск открывает уже работающую сборку; старый/чужой сервер на занятом порте вызывает понятное сообщение, без завершения чужого процесса.
- **boot.js:** проверка протокола до игровых скриптов/аудио/Canvas. При file:// показывается инструкция запуска BAT/HTTP. CORS и защита браузера не отключаются.
- **asset-manifest.json:** явно задан порядок 14 клиентских модулей, CSS, пять обязательных атласов и необязательный декор; версия сверяется с HTML/package.json. Запросы имеют версию и cache: no-store.
- **Загрузчик:** видимый этап и прогресс, проверка HTTP-статуса/MIME/Canvas/обязательных функций, ограничение ожидания запроса и декодирования, ошибка с именем файла в интерфейсе и консоли. Некорректный скрипт останавливает инициализацию. Повторная попытка перезагружает страницу, не переобъявляя глобальные const и не создавая второй игровой цикл.
- **visuals.js → initializeVisuals():** графика загружается под контролем загрузчика. Изображения читаются по HTTP в Blob URL; портреты остаются origin-clean. Цикл начинается после успешной инициализации меню. Все прежние спрайты и анимации сохранены.
- **rpg.html:** загрузочный экран и рабочая кнопка повтора находятся вне inert-контейнера игры; недогруженное меню остаётся заблокированным. При отсутствии самого boot.js показывается отдельная инструкция.
- **audio.js:** загрузка отдельных эффектов сообщает точный путь/ошибку и не прерывает остальные клипы. Аудио запрашивается после жеста пользователя, игровые скрипты не запускаются в file://.
- **server.js:** выдаёт загрузчик, manifest и /version.json с корректными MIME; отсутствующий разрешённый файл возвращает 404 с именем и записью в консоли. Смешанные версии package/manifest выявляются до запуска сервера.
- **tools/check-startup.js:** проверяет наличие/синтаксис модулей, порядок/версию manifest, обязательные изображения и 48 WAV.

Баланс, вероятности сундуков, предметы, навыки, экономика, добыча, задания, души и сетевая симуляция не изменялись.

## Реально выполненные проверки

- `npm run check`: синтаксис, файлы ресурсов и согласованность сборки.
- `npm test`: **36 успешных тестов**, включая шесть новых проверок запуска. Проверены схема manifest/порядок модулей/импорты/48 WAV, блокировка file:// до fetch и Canvas, инструкция BAT, несовместимые версии/пути и реальный Node-launcher из другой рабочей директории. Отдельно проверены повторный запуск и порт со старой версией.
- `npm run test:startup`: чистая загрузка и reload, главное меню, выбор мага, одиночная игра, движение, 48 звуковых буферов, инвентарь/навыки/магазин/кузница, три клиента в IP-лобби и запуск хозяином. Специально вызваны 404 обязательного изображения/скрипта, 500 CSS, неправильный MIME JS, исключение модуля, повреждение изображения, смешанная версия и зависший запрос; для ошибок проверены имя файла и восстановление через кнопку повтора. Отказ логотипа/фона не останавливает игру; отказ одного WAV оставляет 47 исправных эффектов и сообщает его имя.
- Все пять прежних браузерных сценариев пройдены: `test:browser`, `test:tactical`, `test:nythravel`, `test:world`, `test:progression`. Сохранены одиночная игра, два локальных игрока, комнаты по IP/коду, до трёх сетевых клиентов, бой/способности/навыки, торговля/обмен/добыча, кузница/души/задания и карта.
- В штатном HTTP-запуске не обнаружены ошибки JavaScript и запросов обязательных ресурсов. Намеренные ошибки в негативных сценариях диагностируются, затем проверяется восстановление.
- Архив проверяется CRC и повторными проверками из распакованной папки. Проверяется запуск через npm install/npm start и путь с пробелами/кириллицей.

## Как запускать исправленную игру

На Windows: установить Node.js LTS 20+ → распаковать архив целиком в отдельную папку → дважды нажать **START_NYTHRAVEL.bat**. Окно сервера оставить открытым. Браузер откроется по http://127.0.0.1:3000. При ручном запуске: npm install, npm start, затем http://localhost:3000.

## Границы проверки

Проверки выполнены на Linux/Chromium. Сам Windows BAT и открытие системного браузера через rundll32 не исполнялись на реальной Windows: проверены текст BAT/кавычки/CRLF и его Node-launcher. Прямой file:// переход в доступном управляемом Chromium запрещён политикой среды; ветка защитного сообщения проверена исполнением boot.js с file:// и DOM-моделью, а HTTP-игра — настоящим браузером. Пользовательский CORS-журнал подтверждает исходную схему запуска. Не заявляются проверки реального Wi-Fi/NAT, всех браузеров или длительных игровых сессий. Прежние ограничения сохранений/античита перечислены в TEST_REPORT.md.
