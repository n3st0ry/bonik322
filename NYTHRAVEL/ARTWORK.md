# Ресурсы NYTHRAVEL 6

Все ресурсы поставляются локально. Runtime не обращается к генераторам изображений, синтезаторам речи или внешним CDN.

- nythravel-background.webp — ранее созданный фэнтезийный фон меню. Логотип, SVG/ICO favicon и PNG-иконка приложения сохранены после ребрендинга. Кнопки и текст интерфейса — настоящие HTML-элементы.
- v5-heroes.webp — созданный для обновления прозрачный атлас 8×5: пять классов, по восемь кадров. Idle, три положения шага, два атаки, hurt и death. Шаг зависит от реальной скорости, направление оружия рисуется отдельно.
- v5-enemies.webp — прозрачный атлас 5×4, 19 архетипов обычных врагов; одна ячейка резервная. Движение конечностей, атаки, ранения и смерть дополняются Canvas-анимацией.
- v5-bosses.webp — прозрачный атлас 3×3: семь сохранённых боссов, мини-босс и разлом. Предупреждения атак и элитные метки рисуются кодом.
- v5-merchant.webp — прозрачный атлас 2×2, подготовленный по приложенной пользователем лавке: три положения ожидания и приветствие. Изображение адаптировано под игровую перспективу и не содержит интерактивных кнопок. Столкновение, E, торговля и безопасная область реализованы кодом.
- v5-environment.webp — прозрачный атлас 4×3: четыре дерева, каменные залежи, кристаллы, куст, руины, палатка, стена и фонарь. Используется для ресурсных объектов и точек карты; коллизии/пути определяются игровой моделью.
- assets/audio — 42 синтезированных WAV-эффекта (21 семейство × два варианта), плюс шесть WAV приветствий (три фразы × два файла). Фразы синтезированы локально FFmpeg/CMU Flite, голос AWB, **на английском**. Второй файл каждой фразы дублирует исходную запись; runtime меняет тон. Русский текст реплик отображается над лавкой. Это синтезированная речь, не запись актёра.

Новые спрайтовые атласы созданы генератором изображений для этого проекта, преобразованы в WebP с альфа-каналом. Внешние художественные материалы дополнительно не скачивались. Процедурные растения, земля, дороги, мосты, эффекты, оружие и тени рисуются Canvas. Сценарий синтеза эффектов сохранён в tools/generate-audio.py; Python/FFmpeg не требуются для запуска игры.

Персонажи используют покадровые позы; враги — отдельные статические базовые ячейки с процедурной артикуляцией/поворотами/цветом. Полные независимые многокадровые атласы каждого состояния каждого врага не заявляются. Направление тела использует левое/правое отражение, оружие и сектор атаки поворачиваются на 360°.
